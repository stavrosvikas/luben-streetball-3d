# Luben Streetball 1vs1 — 3D κάτοψη

Ισομετρική 3D προβολή του γηπέδου Σαρκουδίνου (Νέος Κόσμος) για το event της 14.11.2026, χτισμένη αυτόματα από την τελική κάτοψη του Illustrator.

Είναι μία σελίδα: Three.js από CDN, χωρίς build και χωρίς dependencies.

## Άνοιγμα

```bash
python -m http.server 8765
```

Μετά άνοιξε `http://localhost:8765`. Χρειάζεται server, γιατί το logo φορτώνεται ως texture. Δουλεύει όπως είναι και σε GitHub Pages.

## Πώς ενημερώνεται από νέα κάτοψη

1. Κάνε export την κάτοψη από το Illustrator σε PDF (ίδια χρώματα, ίδιο artboard).
2. Τρέξε:
   ```bash
   pip install pymupdf
   python tools/extract.py path/to/katopsi.pdf
   ```
   Ξαναγράφει τα `plan.json` / `plan.js` σε μέτρα. Την κλίμακα την παίρνει από το περίγραμμα της περίφραξης: η πρώτη πλευρά είναι 39,85 m.
3. Κάνε refresh τη σελίδα.

Τα αντικείμενα αναγνωρίζονται από το χρώμα τους στην κάτοψη:
